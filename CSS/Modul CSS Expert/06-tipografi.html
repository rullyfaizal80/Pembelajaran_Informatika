Tipografi

Perhatikan bagaimana font serif (judul) dan sans-serif (isi) dipasangkan, serta bagaimana font-size, font-weight, dan color membentuk hierarki.

Skala judul
Judul Utama (t1)
Sub Judul (t2)
Judul Bagian (t3)
Teks keterangan sekunder (t4) — biasanya dipakai untuk deskripsi tambahan.
“Desain yang baik adalah desain yang paling sedikit terlihat sebagai desain.” — Dieter Rams
  • Marka daftar kustom dibuat lewat ::before, bukan list-style bawaan.
  • Memberi kontrol penuh atas bentuk dan warna penanda.
  • Cocok dipakai untuk daftar fitur atau langkah singkat.
/* pasangan font judul & isi */
h1 { font-family: 'Fraunces', serif; }
p  { font-family: 'Inter', sans-serif; }
