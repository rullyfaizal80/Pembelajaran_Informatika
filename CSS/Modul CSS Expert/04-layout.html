Flexbox & Grid

Flexbox untuk penataan satu dimensi (baris atau kolom), Grid untuk penataan dua dimensi sekaligus (baris dan kolom bersamaan).

Setiap kotak diberi flex: 1 sehingga lebarnya terbagi rata.
